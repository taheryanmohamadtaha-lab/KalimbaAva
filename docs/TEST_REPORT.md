# گزارش تست

## چه چیزی واقعاً اجرا شد (محیط توسعه، بدون اندروید)
منطق خالص موسیقی (پوشه‌ی `core/`) با کامپایلر Kotlin 2.0.21 کامپایل و **۳۱ تست از ۳۱ پاس شد**:
تبدیل فرکانس↔نت و سنت، کالیبراسیون A4، نگاشت کلیدهای کالیمبا و چیدمان فیزیکی، تجزیه و اعتبارسنجی آهنگ (نت/سکوت/آکورد/سه‌تایی)،
بخش‌بندی و مدت، امتیازدهی تمرین (درست/اشتباه/از‌دست‌رفته/اضافه، عدم امتیاز ساختگی، انحراف زمانی)،
YIN روی سینوس‌ها و نویز و سکوت، **تشخیص هر ۱۷ کلید روی صدای سینتی‌سایزر**، ردیاب نت (یک رویداد برای هر نواختن، از جمله تکرار یک نت)،
میکسر/ریورب، منطق XP و رکورد پیاپی.
همچنین هر ۲۶ آهنگ و ۳۹ درس با همان تجزیه‌گر اعتبارسنجی شدند.

## چه چیزی اجرا نشد

  ساخت را GitHub Actions انجام می‌دهد؛ اگر خطای کامپایلی گزارش شد، متن خطا را بفرست تا رفع شود.
- تست دستگاهی (تأخیر صدا، چندلمسی، میکروفون با کالیمبای واقعی، باتری، اندازه‌های صفحه) هنوز انجام نشده و نیازمند گوشی واقعی است.
- تست‌های Room/instrumentation نوشته نشده‌اند.
