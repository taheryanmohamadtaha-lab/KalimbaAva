# وضعیت امکانات

## پیاده‌سازی‌شده در کد
- رابط فارسی راست‌به‌چپ، تم چوبی روشن/تیره، ناوبری پایین با ۶ بخش، صفحه‌ی آغاز، دکمه‌ی خروج، نام سازنده
- کالیمبای مجازی ۱۷ کلید: لمس چندانگشتی، کشیدن انگشت (گلیساندو)، انیمیشن لرزش کلید، شماره/نام نت، بلندی صدا، پژواک، ماندگاری، ضبط اجرا (ذخیره به WAV)
- ۳۹ درس (۱۲ + ۱۰ + ۹ + ۸) با آزمونک، پیشرفت و تمرین تعاملی
- ۲۶ آهنگ، دسته‌بندی ایرانی/بین‌المللی، علاقه‌مندی، جستجو، تبلچر، وارد کردن بسته‌ی JSON
- موتور تمرین: تایم‌لاین نت‌های افتان، سرعت‌های ۲۵/۵۰/۶۰/۷۵/۹۰/۱۰۰٪، بخش‌ها، حلقه، توقف/ادامه، شمارش معکوس، سه حالت، ساز مجازی یا میکروفون
- امتیازدهی واقعی (درست/اشتباه/از‌دست‌رفته/اضافه، دقت، زمان‌بندی، انحراف) و پیشنهادهای مبتنی بر اشتباهات واقعی
- تشخیص نت با میکروفون: YIN + آستانه‌ی نویز + حداقل اطمینان + تأیید پایدار + حذف تکرار + تشخیص نواختن دوباره؛ اطمینان فقط از خروجی الگوریتم
- تیونر با کالیبراسیون A4، نمایش نت/اُکتاو/هرتز/سنت/اطمینان
- مترونوم (۳۰–۲۴۰، میزان‌ها، تأکید ضرب اول، ۳ صدا، نمایش بصری)
- ضبط میکروفون، کتابخانه‌ی ضبط (پخش، تغییر نام، حذف، اشتراک)، زمان‌سنج تمرین، هدف روزانه، آمار هفتگی
- پروفایل محلی: XP، سطح، نشان‌ها، رکورد پیاپی، حذف همه‌ی داده‌ها
- Room + DataStore، آفلاین کامل، ورک‌فلو GitHub Actions

## کنار گذاشته‌شده یا محدود (صادقانه)
- **تشخیص چندنتی (پلی‌فونیک) پیاده‌سازی نشده**؛ فقط تک‌نت. در رابط هم همین گفته می‌شود.
- **نمونه‌ی صوتی ضبط‌شده نداریم**؛ صدا ساخته‌شده با مدل فیزیکی است (جزئیات در LICENSES.md).
- تغییر اُکتاو ساز مجازی پیاده‌سازی نشد (دامنه‌ی ۱۷ کلید ثابت است).
- درس‌های سطح ۳ و ۴ کوتاه‌ترند و تصویر/نت‌نگاری حامل (Staff) ندارند؛ نمایش با تبلچر و کلیدهای روشن‌شده است.
- آهنگ‌های سنتی/نوستالژیک ایرانی مشخص (به‌خاطر مجوز) اضافه نشده‌اند؛ قطعات ایرانی موجود اورجینال‌اند. می‌توانی بسته‌ی خودت را اضافه کنی.
- ماژول‌بندی گرادل چندماژوله و Hilt استفاده نشد؛ برای کاهش خطای ساخت یک ماژول `app` با بسته‌های جدا و یک Container دستی داریم.
- ویرایشگر ملودی سفارشی (فاز ۳) و Media3 پیاده‌سازی نشد.
- نمایش سه‌گانه‌ی «تصاویر آموزشی» در درس‌ها محدود به نمایش خود ساز است.
