# کالیمبا آوا – Kalimba Ava 🎼

آکادمی اندروید برای یادگیری کالیمبا ۱۷ کلید، فارسی و راست‌به‌چپ، کاملاً آفلاین.
**سازنده: محمد طاها** — بسته‌ی برنامه: `com.kalimba.ava`

## امکانات
- کالیمبای مجازی ۱۷ کلید (گام دو ماژور، C4 تا E6) با لمس چندانگشتی، پژواک، ماندگاری صدا و ضبط اجرا
- ۳۹ درس در ۴ سطح (مبتدی تا حرفه‌ای) با توضیح فارسی، نمایش کلیدها، نمونه‌ی صوتی، تمرین تعاملی و آزمونک
- ۲۶ ملودی (حوزه‌ی عمومی + آثار اصلی CC0) با تبلچر، بخش‌بندی، سرعت ۲۵ تا ۱۰۰٪ و حلقه
- تمرین هوشمند: حالت راهنما / تمرین / اجرا، با ساز مجازی **یا ساز واقعی از طریق میکروفون** و گزارش واقعی (درست، اشتباه، از‌دست‌رفته، دقت، زمان‌بندی)
- تیونر کروماتیک و تشخیص نت (YIN)، مترونوم، ضبط صدا، زمان‌سنج تمرین
- پروفایل محلی: سطح، امتیاز، نشان‌ها، رکورد روزانه، نمودار هفتگی
- دکمه‌ی «خروج از برنامه» در صفحه‌ی اصلی
- بسته‌های آهنگ JSON قابل افزودن بدون تغییر کد

## ساخت APK (بدون نیاز به برنامه‌نویسی)
1. یک مخزن خالی در GitHub بساز و همه‌ی فایل‌های این پوشه را در آن آپلود کن (یا `git push`).
2. به تب **Actions** برو؛ ورک‌فلو «Android Build» روی هر push خودکار اجرا می‌شود (یا Run workflow را بزن).
3. پس از سبز شدن، از پایین صفحه‌ی اجرا، آرتیفکت **Kalimba-Ava-debug** را دانلود کن؛ داخلش `Kalimba-Ava.apk` است.
4. APK را روی گوشی نصب کن (نصب از منبع ناشناس را اجازه بده).

> نسخه‌ی Release امضاشده فقط وقتی ساخته می‌شود که در GitHub Secrets این چهار مقدار را بگذاری:
> `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD` و ورک‌فلو را با گزینه‌ی release اجرا کنی.
> هیچ کلید یا رمزی در مخزن ذخیره نمی‌شود.

## ساختار
```
app/src/main/java/com/kalimba/ava/
  core/    منطق خالص موسیقی: نت، چیدمان کالیمبا، YIN، ردیاب نت، سینتی‌سایزر، میکسر، امتیازدهی (تست‌شده)
  audio/   موتور صدای کم‌تأخیر (AudioTrack)، میکروفون (AudioRecord)، مترونوم، WAV
  data/    Room، DataStore، بارگذاری بسته‌های محتوا
  ui/      Jetpack Compose (صفحه‌ها و سازِ مجازی)
app/src/main/assets/songs/    بسته‌های آهنگ (JSON)
app/src/main/assets/lessons/  درس‌ها (JSON)
tools/                        اسکریپت‌های تولید آهنگ و درس
docs/                         مستندات
```
